# \# Ahanaf Mokammel Omi — Portfolio

# 

# An interactive, game-inspired personal portfolio designed in the visual language of \*Metaphor: ReFantazio\*.

# 

# The portfolio presents my professional journey, technical skills, projects, experience, research, and creative work through an immersive, menu-driven interface.

# 

# \---

# 

# \## Overview

# 

# This portfolio combines a cinematic game-menu experience with a modern, responsive web interface.

# 

# It features keyboard navigation, interactive transitions, touch-friendly layouts, and dedicated screens for different sections of my professional profile.

# 

# \---

# 

# \## Screens

# 

# The portfolio includes the following sections:

# 

# \- \*\*Journey\*\* — Personal introduction and professional direction

# \- \*\*Projects\*\* — Selected software development and engineering projects

# \- \*\*Abilities\*\* — Technical skills and capabilities

# \- \*\*Experience\*\* — Professional and organizational experience

# \- \*\*Research\*\* — Academic research and publications

# \- \*\*Creative\*\* — Creative work and interests

# \- \*\*About\*\* — Personal and professional background

# \- \*\*Contact\*\* — Contact information and professional links

# \- \*\*Settings\*\* — Interface preferences and settings

# 

# \---

# 

# \## Features

# 

# \- Interactive game-inspired portfolio interface

# \- Keyboard-first navigation on desktop

# \- Arrow keys for navigation

# \- Enter key for selection

# \- Backspace key for returning to previous screens

# \- Mouse hover and click interactions

# \- Touch-friendly layouts for mobile devices

# \- Responsive design for portrait and landscape orientations

# \- Animated screen transitions

# \- Modular content organization

# \- Modern typography and visual styling

# 

# \---

# 

# \## Technology Stack

# 

# \- \*\*React 18\*\* — User interface development

# \- \*\*TypeScript\*\* — Type-safe application development

# \- \*\*Vite\*\* — Development server and build tooling

# \- \*\*Framer Motion\*\* — Animations and transitions

# \- \*\*HTML5\*\*

# \- \*\*CSS3\*\*
